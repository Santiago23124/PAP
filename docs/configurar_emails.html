📧 Configuração de Emails - Sistema de Reservas

✅ Sistema de Emails Implementado!

O sistema de emails está ativo e funcionando. Quando uma reserva é criada:

  • 📧 Email de confirmação é enviado para o cliente
  • 🔔 Email de notificação é enviado para o restaurante
  • 📋 Templates HTML profissionais são usados

🔧 Métodos de Configuração

1. XAMPP Local (Atual - Mais Simples)

Vantagens: Configuração simples, funciona offline

Desvantagens: Emails podem ir para spam, limitado

Como Configurar:

  1. Instale o Mercury Mail Server (incluído no XAMPP)
  2. Inicie o Mercury no painel de controlo do XAMPP
  3. Configure o seu cliente de email (Outlook, Thunderbird) para receber emails locais
# Configuração atual em config/database.php: const SMTP_HOST = 'localhost'; const SMTP_PORT = 25; const SMTP_USERNAME = ''; const SMTP_PASSWORD = '';

2. Gmail SMTP (Recomendado para Produção)

Vantagens: Emails entregues corretamente, não vão para spam

Desvantagens: Precisa de conta Gmail e password de app

Passo 1: Criar Password de App no Gmail

  1. Aceda à sua conta Google
  2. Vá a "Segurança" → "Verificação em 2 passos"
  3. Clique em "Senhas de app"
  4. Crie uma nova password de app para "Mail"
  5. Copie a password gerada (16 caracteres)

Passo 2: Alterar Configurações

Edite o ficheiro config/database.php e altere:

// Descomente estas linhas e configure: const SMTP_HOST = 'smtp.gmail.com'; const SMTP_PORT = 587; const SMTP_USERNAME = 'seu-email@gmail.com'; const SMTP_PASSWORD = 'sua-password-de-app-16-chars';

3. Outlook/Hotmail SMTP

Vantagens: Funciona bem, emails entregues

const SMTP_HOST = 'smtp-mail.outlook.com'; const SMTP_PORT = 587; const SMTP_USERNAME = 'seu-email@outlook.com'; const SMTP_PASSWORD = 'sua-password';

4. Outros Provedores

  • Yahoo: smtp.mail.yahoo.com:587
  • IOL: smtp.iol.pt:587
  • Sapo: smtp.sapo.pt:587
  • Provedor personalizado: Contacte o seu provedor

⚠️ Importante

  • Para Gmail/Outlook, precisa ativar a verificação em 2 passos
  • Use sempre passwords de app, não a password normal
  • Teste sempre após alterar configurações
  • Emails podem demorar alguns minutos a chegar

🧪 Testar Sistema de Emails

Testes Disponíveis:

📧 Teste de Emails 🧪 Teste Completo 🌐 Página de Reservas

Como Testar:

  1. Configure o método escolhido em config/database.php
  2. Teste o sistema com um dos links acima
  3. Verifique a caixa de entrada do email que inserir
  4. Verifique o spam se não receber

📋 Checklist de Configuração

✅ Verificações:

  • □ Configurações SMTP definidas corretamente
  • □ Password de app criada (se Gmail/Outlook)
  • □ Verificação em 2 passos ativada
  • □ Sistema testado com email real
  • □ Emails chegam à caixa de entrada
  • □ Templates HTML são exibidos corretamente

🔍 Resolução de Problemas

❌ Emails não são enviados:

  • Verifique as configurações SMTP
  • Confirme que a password de app está correta
  • Verifique se a verificação em 2 passos está ativada
  • Teste com um email diferente

📧 Emails vão para spam:

  • Use um provedor SMTP confiável (Gmail, Outlook)
  • Configure SPF e DKIM no seu domínio
  • Use um email profissional para o restaurante
