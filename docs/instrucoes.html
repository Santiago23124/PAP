🔧 Instruções para Resolver o Problema de Reservas

1. Verificar XAMPP

Certifique-se que o XAMPP está a correr:

  • Apache (porta 80) ✅
  • MySQL (porta 3306) ✅

2. URL Correta para Aceder ao Site

Use esta URL exata no seu browser:

http://localhost/TP1_RC_WEB_Santiago_22453/TP1_RC_WEB_Santiago_22453/Reservas.html

⚠️ IMPORTANTE: Note que há duas pastas com o mesmo nome!

3. Testar a API Diretamente

Primeiro, teste se a API está acessível:

http://localhost/TP1_RC_WEB_Santiago_22453/TP1_RC_WEB_Santiago_22453/api/reservas.php

Se abrir uma página em branco, a API está funcionando. Se der erro 404, há problema no caminho.

4. Teste Rápido

❌ Se Continuar a Dar Erro

Possíveis soluções:

  1. Reiniciar XAMPP: Pare e inicie novamente Apache e MySQL
  2. Verificar porta: Se a porta 80 estiver ocupada, use porta 8080
  3. URL alternativa: http://localhost:8080/TP1_RC_WEB_Santiago_22453/TP1_RC_WEB_Santiago_22453/Reservas.html
  4. Verificar firewall: Pode estar a bloquear ligações locais
